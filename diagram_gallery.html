🔑 id

🔔 Notification
🔑 id
FK userId → User
message, type
isRead, createdAt

Relationships

User 1 ──▶ N CropListing (farmer creates listings)
User 1 ──▶ N Order (kitchen places orders)
CropListing 1 ──▶ N Order (listing has multiple orders)
Order 1 ──▶ 1 DeliveryAssignment (one partner per order)
Order 1 ──▶ 1 Verification (one verification per order)
Order 1 ──▶ 1 Payment (one payment per order)
Order 1 ──▶ N Dispute (multiple disputes possible)
User 1 ──▶ N Notification (user receives notifications)
